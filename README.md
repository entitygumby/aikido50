# aikido50

50th Anniversary Seminar page for Takemusu Aiki Australia.

## Project Structure

```
aikido50/
├── index.html              # Main seminar webpage
├── css/
│   └── styles.css          # Website styles
├── js/
│   └── gallery.js          # Photo gallery lightbox functionality
├── images/
│   └── gallery/            # Photo gallery images (add your photos here)
└── README.md
```

## Adding Photos to the Gallery

To add your photos to the gallery:

1. Place your photos in the `images/gallery/` folder
2. Name them `photo-01.jpg` through `photo-20.jpg`
3. Supported formats: JPG, PNG, WEBP

The gallery will automatically display all 20 photos with:
- Responsive grid layout
- Hover effects
- Click-to-enlarge lightbox with keyboard navigation (arrow keys, escape)

## Features

- Responsive design (mobile, tablet, desktop)
- Seminar schedule for Day 2
- Registration & payment information
- Venue details with map
- Photo gallery with lightbox
- Contact information

## Customization

### Updating Contact Information
Edit the placeholder phone number `(02) xxxx` in `index.html` under the venue section.

### Updating Photos
Replace the placeholder images in `images/gallery/` with actual seminar photos.
