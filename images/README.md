# Image Assets

Add your Aikido images to this directory with the following filenames:

- `aikido-1.jpg` - First carousel image
- `aikido-2.jpg` - Second carousel image
- `aikido-3.jpg` - Third carousel image
- `aikido-4.jpg` - Fourth carousel image

Recommended image specifications:
- Resolution: 1920x1080 pixels minimum (landscape orientation)
- Format: JPG or PNG
- Content: Aikido practice, demonstrations, or dojo photos

The carousel will automatically rotate through these images every 5 seconds.
