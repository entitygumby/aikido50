# Japan Tour 2012 photos

Photos for `japan-tour-2012.html`. Name each file after its photo slot ID and save it as `.jpg`;
the page picks it up automatically and falls back to a labelled placeholder until then.

- `hero.jpg`: magazine layout lead image (landscape, 21:9)
- `dNN-N.jpg`: day photos, e.g. `d05-1.jpg` is the first photo for Day 5

The slot IDs and captions are listed on the page itself (each placeholder shows its ID).
