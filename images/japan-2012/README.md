# Japan Tour 2012 photos

Photos for `japan-tour-2012.html`. Each file is named after its photo slot ID (`dNN-N.jpg`, e.g. `d05-1.jpg` is
the first photo for Day 5). The page loads it automatically and falls back to a labelled placeholder if it's missing.

Slots and captions live in the `photos` array of each `DAYS` entry in the page; IDs follow their order.

Export spec: 1600 px on the long edge, JPEG quality 80, sRGB, EXIF/GPS stripped.

## Source frames

Originals are in the trip folders (01–12 by day; 03 covers both walking days).
